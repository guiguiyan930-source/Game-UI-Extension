# Game UI Screen Taxonomy

Use this reference when expanding a game into a full UI screen set. Select only categories that fit the game's genre, platform, and core loop.

## 1. Launch, Login, and First Impression

Screens that define the player's first contact and entry flow.

| Screen | Typical Content | Notes |
|---|---|---|
| Splash / boot | Logo, publisher, engine, loading bar | Keep brand and game tone clear. |
| Login / register | Account, guest, third-party login, privacy agreement | Include region and age gates when required. |
| Announcement modal | Patch notes, event notice, maintenance info | Use forced or optional display intentionally. |
| Server selection | Server list, status, recommended server, character marker | Useful for MMO and region-sharded games. |
| Character creation / selection | Class, avatar, appearance, name, existing slots | Preview combat role and long-term identity. |
| Opening story / loading transition | CG, narrative text, tips, progress | Connect worldbuilding with scene loading. |
| New player tutorial overlay | Guided taps, tooltip masks, step progress | Avoid blocking the player's first meaningful action for too long. |

## 2. Core Gameplay

Screens where the core loop is performed or launched.

| Screen | Typical Content | Notes |
|---|---|---|
| Main lobby / city / home | Feature entrances, resource bar, task tracker, event entry | Prioritize daily return actions and next objective. |
| Quest / story | Main, side, daily, event quests, rewards, dialogue | Make "track", "go", and "claim" fast. |
| Battle HUD | HP, skills, cooldowns, teammates, minimap, pause, objective | Fit the input model and avoid occluding play space. |
| Gameplay preparation | Matchmaking, team, loadout, talents, difficulty | Surface readiness and risk/reward before entry. |
| Stage / dungeon select | Map, chapters, difficulty, stars, drops | Show progress and farm value clearly. |
| Results / settlement | Rewards, score, stars, XP, rank change, retry | The reward reveal should feel earned and readable. |
| Pause / fail / revive | Resume, settings, quit, revive, retry | Avoid accidental exits during high-stakes play. |

## 3. System and Growth

Screens for inventory, character management, and long-term progression.

| Screen | Typical Content | Notes |
|---|---|---|
| Inventory / warehouse | Items, materials, equipment, filters, use/sell/disassemble | Include capacity and batch operations. |
| Character / hero detail | Attributes, skills, art, biography, level, rarity | Support comparison and role understanding. |
| Equipment | Equip, enhance, refine, socket, set bonus, dismantle | Show before/after values and resource cost. |
| Skills / talents | Skill upgrade, tree, rune, gem, passive nodes | Make prerequisites and build direction visible. |
| Ascension / breakthrough | Stars, evolution, awakening, required materials | Show source shortcuts for missing materials. |
| Companion systems | Pets, mounts, vehicles, familiars, assists | Explain passive and active effects. |
| Achievements / titles | Milestones, badges, titles, reward claims | Use progress grouping and claim-all carefully. |
| Codex / archive | Monsters, items, lore, gallery, music, cutscenes | Good for collection-heavy games. |

## 4. Economy, Shop, and Monetization

Screens where value, scarcity, and purchase trust matter.

| Screen | Typical Content | Notes |
|---|---|---|
| Shop / mall | Currency shop, packs, limited goods, recharge | Separate earned shops from paid shops. |
| Gacha / summon | Banners, rates, pity, history, one/ten-pull buttons | Probability and guarantee rules must be accessible. |
| Battle pass / season pass | Free/paid tracks, levels, missions, premium unlock | Show progress and remaining time. |
| Monthly card / subscription | Benefits, duration, daily claims, renewal | Make claim state and expiration clear. |
| Currency exchange | Gold, gems, stamina, tickets, conversion | Show rate, limits, and confirmation. |
| Ad reward | Watch ad, reward preview, cooldown | Keep ad value optional and explicit. |

## 5. Events and Live Operations

Screens that drive daily return, limited-time play, and campaign content.

| Screen | Typical Content | Notes |
|---|---|---|
| Sign-in / login rewards | 7-day, monthly, streak, make-up claim | Show missed and future rewards clearly. |
| Daily / weekly tasks | Missions, progress, active points, chests | Prioritize claimable tasks. |
| Event hub | Limited events, tabs, countdowns, rules | Use one hub when event volume is high. |
| Limited challenge | Event stages, modifiers, shop currency, rankings | Link event play with event shop. |
| Festival popup | Seasonal offers, freebies, themed activities | Avoid interrupting critical gameplay. |
| Returner campaign | Comeback rewards, catch-up missions, boosted drops | Provide a clear recovery path. |

## 6. Social, Guild, and Community

Screens that support retention through people and groups.

| Screen | Typical Content | Notes |
|---|---|---|
| Friends | Friend list, add, requests, chat, gift stamina | Include online state and last active. |
| Guild / clan / club | Join/create, members, roles, activity, shop | Separate recruitment from management. |
| Guild activities | Boss, war, quests, donations, tech | Show contribution and shared rewards. |
| Chat | World, guild, private, team, emoji, voice | Include moderation, block, and report. |
| Mail | System, rewards, friend, claim all, delete | Preserve unclaimed reward safety. |
| Player profile | Avatar, level, badges, showcase, records | Used by rankings, friends, and guild discovery. |

## 7. Competitive and Ranking

Screens for PvP, seasons, ladders, and competitive trust.

| Screen | Typical Content | Notes |
|---|---|---|
| PvP lobby | Rank, queue, mode, season timer, rewards | Make current goal and next reward visible. |
| Matchmaking | Queue status, estimated time, cancel, ready check | Provide feedback during waiting. |
| Leaderboard | Power, level, rank, guild, friends filter | Include settlement time and ranking rules. |
| Match history | Opponents, result, replay, stats, report | Useful for learning and disputes. |
| Season summary | Rank change, rewards, reset, highlights | Make reset consequences explicit. |
| Tournament bracket | Participants, schedule, bracket, predictions | Support viewing, reminders, and results. |

## 8. Strategy, Loadout, and Build Planning

Screens for games where preparation is a major part of play.

| Screen | Typical Content | Notes |
|---|---|---|
| Team formation | Slots, positions, roles, synergies, recommended power | Use formation presets and conflict warnings. |
| Deck builder | Cards, cost curve, filters, archetypes, validation | Support search and legality checks. |
| Loadout presets | Weapons, armor, skills, cosmetics, consumables | Allow save, copy, rename, and quick switch. |
| Talent planner | Future nodes, reset, compare, recommended builds | Clarify irreversible choices. |
| AI tactics / behavior | Priorities, auto-skill, targeting, stance | Useful for idle, tactics, and party games. |

## 9. Creation, Collection, and Expression

Screens that let players personalize or create.

| Screen | Typical Content | Notes |
|---|---|---|
| Skins / wardrobe | Outfits, dyes, preview, ownership, equip | Show owned vs purchasable clearly. |
| Housing / decoration | Room, furniture, placement, storage, visitors | Needs edit mode and save/cancel states. |
| Photo mode | Camera, poses, filters, stickers, share | Hide HUD and preserve composition. |
| Replay / theater | Saved matches, bookmarks, timeline, share | Support trim and highlight if relevant. |
| User-generated content browser | Levels, maps, mods, ratings, tags | Include moderation and compatibility. |

## 10. Settings, Support, and Account

Screens that protect comfort, safety, and account continuity.

| Screen | Typical Content | Notes |
|---|---|---|
| Settings | Audio, graphics, controls, language, notifications | Split platform-specific settings where needed. |
| Controls / keybinds | Mapping, sensitivity, presets, test area | Support reset and conflict detection. |
| Accessibility | Subtitles, contrast, colorblind mode, motion, text size | Include gameplay-relevant accessibility, not only visual settings. |
| Account | Bind account, switch, privacy, deletion, restore purchase | Confirmation and support links are important. |
| Customer support | FAQ, ticket, bug report, logs, contact | Attach player ID and device info when possible. |
| Redeem code | Input, validation, history, reward claim | Handle invalid, expired, and already-used codes. |
